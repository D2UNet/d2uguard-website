What it checks

Eight checks, all from public records

The same checks an attacker can run in a minute, explained in words a client’s business owner understands.

Email

SPF

Which services may send mail as the domain, and whether everything else is refused.

Email

DMARC

Whether spoofed mail is rejected, quarantined or still delivered, and whether anyone is watching the reports.

Email

DKIM

Whether outgoing mail is signed, so receivers can tell it has not been altered.

Email

MTA-STS

Whether mail sent to the domain must arrive encrypted, with failure reporting.

Website

Certificate

Whether the certificate is trusted, matches the site and is close to expiring.

Website

TLS and HTTPS

Whether the site uses current TLS and sends http:// visitors to the secure site.

Website

Security headers

HSTS, Content Security Policy, clickjacking protection, MIME sniffing and referrer policy.

Website

Disclosure

Whether the site advertises the software it runs, which helps attackers pick their tools.
